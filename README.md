# Mudviejų ratas

Kasdienis užduočių ratas dviem. Statinis puslapis (GitHub Pages) + Firebase Firestore (projektas `mudvieju-ratas`).

- `index.html` – visa programėlė.
- `news.json` – aktualijų užduotys: `[{"id","date":"YYYY-MM-DD","task","url","title"}]`.
- Duomenys saugomi `rooms/<kambario-kodas>/…`; kodą abu įvedat pirmą kartą arba atidarot nuorodą `…/ratas/#kodas`.
